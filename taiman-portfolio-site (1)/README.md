# Сайт-визитка с ИИ-ассистентом — как запустить

Готовый сайт: страница `index.html` + серверная функция `api/chat.js`, которая отвечает на вопросы посетителей по базе знаний `api/_kb.js` через Claude API.

Займёт около 20 минут. Нужны три бесплатных аккаунта: GitHub, Vercel и Anthropic (Claude API).

## 1. Получить ключ Claude API
1. Зайдите на https://console.anthropic.com и зарегистрируйтесь.
2. **Billing** → пополните баланс минимальной суммой (5 $ хватит надолго: один ответ стоит меньше 0,1 цента).
3. **API Keys** → **Create Key** → скопируйте ключ (начинается с `sk-ant-`). Никому его не показывайте и не вставляйте в файлы сайта.
4. Рекомендую: **Limits** → поставьте месячный лимит расходов, например 5 $.

## 2. Загрузить сайт на GitHub
1. Зайдите на https://github.com → **New repository** → имя, например `portfolio` → **Create repository**.
2. На странице репозитория: **uploading an existing file** → перетащите все файлы и папку `api` из этого архива (index.html, package.json, README.md, api/chat.js, api/_kb.js) → **Commit changes**.

## 3. Опубликовать на Vercel
1. Зайдите на https://vercel.com → **Sign up with GitHub**.
2. **Add New → Project** → выберите репозиторий `portfolio` → **Import**.
3. Раскройте **Environment Variables** и добавьте:
   - Name: `ANTHROPIC_API_KEY`
   - Value: ваш ключ `sk-ant-...`
4. **Deploy**. Через минуту сайт будет доступен по адресу вида `https://portfolio-xxxx.vercel.app`.
5. Короткий адрес: **Settings → Domains** — можно поменять на `taiman-gabbassov.vercel.app` (бесплатно) или подключить свой домен.

## 4. Проверить
Откройте сайт и задайте в строке любой вопрос, например «Какой у тебя опыт с интеграциями?». Ответ придёт за 2–5 секунд с подписью «Ответ сгенерирован ИИ по моему резюме».

Если ИИ недоступен (нет ключа, закончился баланс), сайт не ломается: он отвечает заготовленными ответами.

## Как обновлять информацию
- **Факты для ИИ** — в файле `api/_kb.js`. Откройте его на GitHub → значок карандаша → правьте текст → **Commit changes**. Vercel обновит сайт сам через минуту.
- **Контакты** — указаны в `api/_kb.js` (раздел «Контакты») и в `index.html` (поиск по `taiman.gabbassov`).
- **Тексты страницы** — в `index.html`.

## Настройки в api/chat.js
- `LIMIT_PER_HOUR` — сколько вопросов в час с одного адреса (по умолчанию 30).
- `MAX_Q` — максимальная длина вопроса.
- Модель задаётся переменной окружения `CHAT_MODEL` (по умолчанию `claude-haiku-5-5` — быстрая и дешёвая).
