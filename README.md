# Сайт-визитка с ИИ-ассистентом — как запустить

Готовый сайт: страница `index.html` + серверная функция `api/chat.js`, которая отвечает на вопросы посетителей по базе знаний `api/_kb.js` через Claude API.

Займёт около 20 минут. Нужны три бесплатных аккаунта: GitHub, Vercel и Anthropic (Claude API).

## 1. Получить ключ Claude API
1. Зайдите на https://console.anthropic.com и зарегистрируйтесь.
2. **Billing** → пополните баланс минимальной суммой (5 $ хватит надолго: один ответ стоит меньше 0,1 цента).
3. **API Keys** → **Create Key** → скопируйте ключ (начинается с `sk-ant-`). Никому его не показывайте и не вставляйте в файлы сайта.
4. Рекомендую: **Limits** → поставьте месячный лимит расходов, например 5 $.

## 2. Загрузить сайт на GitHub
1. Зайдите на https://github.com → **New repository** → имя, например `portfolio` → **Create repository**.
2. На странице репозитория: **uploading an existing file** → перетащите все файлы и папку `api` из этого архива (index.html, package.json, README.md, api/chat.js, api/_kb.js) → **Commit changes**.

## 3. Опубликовать на Vercel
1. Зайдите на https://vercel.com → **Sign up with GitHub**.
2. **Add New → Project** → выберите репозиторий `portfolio` → **Import**.
3. Раскройте **Environment Variables** и добавьте:
   - Name: `ANTHROPIC_API_KEY`
   - Value: ваш ключ `sk-ant-...`
4. **Deploy**. Через минуту сайт будет доступен по адресу вида `https://portfolio-xxxx.vercel.app`.
5. Короткий адрес: **Settings → Domains** — можно поменять на `taiman-gabbassov.vercel.app` (бесплатно) или подключить свой домен.

## 4. Проверить
Откройте сайт и задайте в строке любой вопрос, например «Какой у тебя опыт с интеграциями?». Ответ придёт за 2–5 секунд с подписью «Ответ сгенерирован ИИ по моему резюме».

Если ИИ недоступен (нет ключа, закончился баланс), сайт не ломается: он отвечает заготовленными ответами.

## Как обновлять информацию
- **Факты для ИИ** — в файле `api/_kb.js`. Откройте его на GitHub → значок карандаша → правьте текст → **Commit changes**. Vercel обновит сайт сам через минуту.
- **Контакты** — указаны в `api/_kb.js` (раздел «Контакты») и в `index.html` (поиск по `taiman.gabbassov`).
- **Тексты страницы** — в `index.html`.

## Настройки в api/chat.js
- `LIMIT_PER_HOUR` — сколько вопросов в час с одного адреса (по умолчанию 30).
- `MAX_Q` — максимальная длина вопроса.
- Модель задаётся переменной окружения `CHAT_MODEL` (по умолчанию `claude-haiku-5-5` — быстрая и дешёвая).

## Превью ссылки, иконка и аналитика

- `og.jpg`: картинка превью ссылки (1200×630) для Telegram, WhatsApp, LinkedIn.
- `favicon.ico`, `favicon-32.png`, `icon-192.png`, `apple-touch-icon.png`: иконка во вкладке и на экране телефона.
- Все эти файлы лежат в корне репозитория рядом с `index.html`.

Аналитика (Vercel Web Analytics):
1. Vercel → проект → вкладка **Analytics** → **Enable**.
2. Через 5–10 минут после первых визитов там появятся посетители, страны, устройства и источники переходов.
3. Сайт уже отправляет события: открытие разделов (`tab_open`), скачивание резюме (`resume_download`),
   клики по контактам (`contact_click`), вопросы ИИ (`ai_question`), подсказки (`chip_click`), смена языка (`lang_switch`).
   На бесплатном тарифе Vercel показывает только посещения, события видны на тарифе Pro.
   Если подключить Яндекс Метрику, те же события уйдут в неё как цели.

## Журнал вопросов в Telegram

Каждый вопрос к ИИ-ассистенту и его ответ приходят вам в Telegram.
1. В Telegram откройте @BotFather → `/newbot` → придумайте имя и логин (должен заканчиваться на `bot`). Скопируйте токен.
2. Найдите своего бота по логину, нажмите **Start** и напишите ему любое сообщение.
3. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` (вместо `<ТОКЕН>` вставьте токен).
   Найдите `"chat":{"id":123456789`: это число и есть ваш chat_id.
4. Vercel → проект → **Settings → Environment Variables** → добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
5. **Deployments** → у последней сборки «⋯» → **Redeploy**, чтобы переменные подхватились.
Если переменных нет, журнал выключен, сайт работает как обычно.

## Лимиты на вопросы к ИИ-ассистенту

- С одного IP: 30 вопросов в час. На весь сайт: 300 вопросов в сутки (сутки по UTC, сброс в 05:00 по Астане).
- Чтобы лимиты были строгими, подключите бесплатное хранилище:
  1. Vercel → проект → **Storage** → **Create Database** → **Upstash for Redis** (Redis) → бесплатный план → **Create**.
  2. На шаге подключения выберите этот проект. Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.
  3. **Deployments** → у последней сборки «⋯» → **Redeploy**.
- Без хранилища лимит работает приблизительно (в памяти функции), сайт при этом продолжает отвечать.
- Изменить дневной лимит: переменная окружения `DAILY_LIMIT` (например, 500).
- Дополнительно задайте лимит расходов: console.anthropic.com → Settings → Limits.

## Журнал вопросов (Upstash)

Каждый вопрос и ответ ассистента сохраняется в список `chat:log` (последние 2000 записей).
Смотреть: Vercel → Storage → база Upstash → Open in Upstash → Data Browser → ключ `chat:log`.
В записи: время (UTC), язык, страна, метка посетителя, номер вопроса в разговоре, вопрос, ответ, ошибка.
IP-адреса не сохраняются.

## Яндекс Метрика

1. metrika.yandex.ru → Добавить счётчик → адрес сайта, включить Вебвизор → Создать.
2. В index.html найдите строку `window.YM_ID = 0;` и вместо 0 впишите номер счётчика.
3. Цели (события) уходят автоматически: tab_open, resume_download, contact_click, ai_question, chip_click, share, lang_switch.
